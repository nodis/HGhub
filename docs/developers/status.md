# 当前支持状态

审计日期：2026-11-15。应用 0.0.1，协议 1.0.0-dev；不构成五端完整合规声明。

| 范围 | 当前状态 | 验证边界 |
| --- | --- | --- |
| 单文件/列表/URL 导入 | 已实现 | Rust 与 Windows UI；Android 单文件实测 |
| 订阅与自动更新 | 已实现 | 冷却、手动旁路、播放延后回归 |
| 独立运行时与取消 | 核心已实现 | 并发/中断/共享 Promise；内部桥不向插件暴露 |
| HTTP/Cookie/存储 | 核心已实现 | 网络策略、缓存、配额和持久化回归 |
| 内容能力与本地片库 | 已接入 UI | 生产界面虚构源完整集成 25 组通过 |
| MP4/HLS/解析器 | 核心已实现 | Range、密钥、资源归属与取消回归 |
| RSA | 必需 API 尚缺 | requires 拒绝依赖此 API 的插件 |
| 设备能力探测 | 尚缺 | env.media/codecs 为静态值 |
| 字幕 | VTT 接入 | SRT 转 VTT 未实现，ASS 未声明 |
| 外部播放流 | 尚缺 | UNSUPPORTED，缺确认打开流程 |
| 宿主共享刷新 | 尚缺 | 当前由播放消费者刷新，无共享原子映射 |
| 调度 | 有缺口 | 匿名 GET 在途合并、主机并发和媒体优先队列未完成 |
| HTML 内存 | 数量/输入有界 | 尚未合并计入 64 MiB 堆预算 |
| 自检/日志导出/占用与清理 | 尚缺 | 日志读取可用 |
| Android 相对列表 | 尚缺 | content URI 兄弟文件需目录授权 |
| WebView/DASH/下载 | 可选未支持 | 不声明这些特性 |
| 跨端/后台 | 未完成 | Windows 浏览器、Android 导入及单部真实 MP4 播放有证据 |

细节见[实现说明](../plugin-protocol/IMPLEMENTATION.md)。
